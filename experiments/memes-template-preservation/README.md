# Memes and template preservation

## Goal

Change one requested element while preserving the recognized template, reaction, panel structure, and composition.

## Why the public sample is text-only

Historical work used recognizable third-party meme templates. Those image files are not redistributed here. The useful contribution is the preservation method, which can be demonstrated without publishing the template.

## Public sample

See [template-preservation-prompt.md](samples/template-preservation-prompt.md).

## Reusable test

The edit fails if any unrequested element changes:

- panel count;
- character or object positions;
- expression or gesture;
- crop;
- caption zones;
- typography outside the target;
- recognized visual timing of the joke.
