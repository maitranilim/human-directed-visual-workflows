# Sample: Template-preserving local edit

```text
Use the provided template only as a private edit reference.

PRESERVE
- the full canvas and aspect ratio;
- panel count and panel boundaries;
- every character, expression, gesture, and object position;
- the original crop, background, and visual timing;
- all text except the named target.

CHANGE ONLY
- replace “[old text]” with “[new text]” in [specific caption zone].

MATCH
- the existing type weight, alignment, line breaks, spacing, outline, and
  compression quality.

REJECT IF
- any other text, face, object, panel, color, or crop changes.
```

For public distribution, use an original or properly licensed template.
