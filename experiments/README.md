# Experiments

Historical visual work has been reorganized by job type so that a reader can compare requirements, failure modes, and reusable controls.

| Folder | Primary control problem | Public sample policy |
|---|---|---|
| `realistic-photo-editing/` | Preserve scene logic while reducing the AI-edited look | Non-personal scene only |
| `posters-public-causes/` | Combine hierarchy, narrative, exact copy, and cultural care | Concept outputs with limitations |
| `profile-banners-branding/` | Build a compact visual identity across formats | Non-personal symbols and materials |
| `wallpapers-worldbuilding/` | Reuse a world grammar without duplicating a scene | Three related character-world outputs |
| `memes-template-preservation/` | Make a local edit without breaking a known template | Text-only sample, no third-party template |
| `ui-os-concepts/` | Communicate an interaction idea visually | Concept render, not working UI |

## Evidence states

- **Output available:** the selected image is public in the folder.
- **Workflow reconstructed:** repeatable controls are recoverable, but the exact historical prompt is not.
- **Metrics unmeasured:** iteration count and elapsed time were not recorded.
- **Rights-limited:** method is public while the source or template is withheld.

The category README files use these states rather than inventing a complete experimental record.
