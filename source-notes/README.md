# Source notes

`original-style-reference-notes.txt` preserves an earlier, unstructured style and prompt vocabulary.

The structured prompt library is the portfolio contribution:

- terms are grouped by visual function;
- preservation is separated from style;
- composition and final-use constraints are explicit;
- failures produce negative requirements;
- exact text and rights risks are surfaced.

The source note is retained to show the transformation from scattered exploration to a reusable workflow. It may contain broad aesthetic references and should not be treated as a finished production brief.
