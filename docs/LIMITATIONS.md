# Limitations

- The exact prompt transcript is unavailable for some historical outputs.
- Historical iteration counts, elapsed time, and generation costs were not measured consistently.
- Selected outputs show range, not controlled proof that one workflow caused higher quality.
- Text in AI-generated posters and UI concepts may contain artifacts and requires deterministic recreation.
- Cultural, religious, policy, or brand content requires domain review before real use.
- No personal photographs are published, so portrait-preservation claims are documented as a method without public before-and-after evidence.
- “Model behavior shaping” refers to supervised interaction and reusable instructions, not model fine-tuning.
