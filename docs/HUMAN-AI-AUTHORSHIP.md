# Human-AI authorship

## Plain-language disclosure

The images in this repository were generated or edited by AI systems under human direction. `maitranilim` does not claim to have manually illustrated them.

`maitranilim` contributed the visual problems, references, constraints, preservation rules, art direction, critiques, rejection decisions, reusable prompt fragments, and public curation. ChatGPT and image-generation models performed substantial synthesis and editing. Codex helped organize and document the workflow.

## Accurate vocabulary

| Phrase | Use it here? | Meaning |
|---|---|---|
| AI-generated or AI-edited output | Yes | The model produced or transformed the pixels |
| Human-directed AI visual work | Yes | The human materially controlled goals, constraints, critique, and selection |
| Multimodal art direction | Yes | The human directed composition, mood, typography, palette, and reference use |
| Prompt systems design | Yes | Successful language was decomposed into reusable controls |
| Iterative supervision | Yes | Outputs were reviewed, corrected, and accepted or rejected |
| Model behavior shaping | Yes, with scope | Feedback changed output behavior within the workflow |
| Hand-drawn or manually illustrated | No | That would misdescribe production |
| Fine-tuned the model | No | No model fine-tuning is represented |
| Trained ChatGPT | No | There is no evidence that base-model weights changed |

## Credit rule

A human contribution is material when it changes:

- the problem or audience;
- the reference and preservation boundary;
- composition or hierarchy;
- style, palette, material, or finish;
- the critique or acceptance criterion;
- the minimal repair;
- the reusable workflow;
- the privacy or publication decision.

## Model-learning boundary

Repeated feedback can improve the model’s output during an interaction and can improve a user-owned library of instructions. That is valuable model behavior shaping. It is not the same as permanent model training.
