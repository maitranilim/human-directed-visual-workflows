# Repeatable visual workflow

## 1. Define the job

State:

- deliverable;
- audience;
- channel;
- aspect ratio and target dimensions;
- action the viewer should take or feeling they should retain;
- deadline and acceptable number of iterations.

## 2. Inspect the source

List:

- subject and scene;
- camera angle and crop;
- important negative space;
- dominant colors and lighting;
- text that must remain exact;
- identity, brand, cultural, and rights risks.

## 3. Write preservation locks

Create a separate “must not change” block. Treat it as an invariant list, not a polite preference.

## 4. Assemble prompt fragments

Choose one fragment from each needed layer:

- subject;
- composition;
- style family;
- typography;
- palette and lighting;
- material and finish;
- negative constraints;
- final-result target.

Do not stack every fashionable style word. Each fragment should have a job.

## 5. Generate or edit

Record the model, date, prompt version, source class, and iteration number. Do not publish a source image merely because the output is publishable.

## 6. Critique the delta

Compare the result with the brief:

- What changed correctly?
- What changed that was locked?
- What is missing?
- What single correction would create the most value?

## 7. Apply the smallest repair

Prefer a local instruction:

> Keep everything else unchanged. Correct only [target]. Preserve [locks].

Regenerate the whole composition only when the core concept or geometry is wrong.

## 8. Run visual QA

Check:

- composition;
- preservation;
- realism or intended stylization;
- text fidelity;
- brand and cultural accuracy;
- privacy and rights;
- channel dimensions;
- file quality.

## 9. Archive the reusable part

Save:

- the successful fragment;
- the failure it prevents;
- applicable categories;
- known conflicts;
- output evidence;
- iteration and time data, if actually recorded.
