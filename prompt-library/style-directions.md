# Style directions

Choose one primary family and, at most, two supporting families.

| Style family | Use when | Useful controls | Common failure |
|---|---|---|---|
| Retrofuturism | The future should feel imagined through an earlier era | Analog hardware, old interfaces, optimistic or worn future | Random nostalgia without a time logic |
| Neo-futurism | The direction needs clean, synthetic, architectural clarity | Smooth geometry, high-tech minimalism, controlled negative space | Generic “futuristic” gloss |
| Techno-brutalism | The layout needs force, hierarchy, and industrial urgency | Harsh grid, oversized type, warning labels, functional panels | Unreadable density |
| Y2K futurism | Early-internet or chrome interface energy is useful | Translucent panels, metallic color, curved UI, glossy type | Decorative chrome everywhere |
| Cassette futurism | Machines should feel tactile and pre-digital | CRTs, buttons, cables, chunky forms, worn housings | Prop clutter |
| Dystopian editorial | Fashion, technology, and narrative tension must coexist | Serious subject, controlled lighting, magazine hierarchy | Costume without story |
| Transhumanist cybernetics | Human-machine identity is the core question | Visors, implants, neural hardware, body-tech interfaces | Body horror or identity drift |
| Swiss grid futurism | Information must feel disciplined and premium | Alignment, spacing, typographic rhythm, sparse geometry | Clean but emotionally empty |
| Glitchcore | Corruption or instability is semantically relevant | Scanlines, compression, broken pixels, fragmented text | Noise that destroys hierarchy |
| Mecha UI | Armored machine logic should shape the frame | Panels, mechanical joints, layered interfaces | Detail without focal point |

## All-purpose editorial stack

Use carefully:

> cyberpunk + retrofuturism + techno-brutalism + HUD interface design + experimental typography + dystopian editorial + restrained glitch + neon noir

This works best when one direction is declared primary. Remove any term that does not change a visible decision.

## Direction sentence

```text
Use [primary style] as the design system, supported by [secondary style]
for [specific function]. Avoid [known conflicting look].
```

Example:

```text
Use techno-brutalism as the layout system, supported by restrained HUD
linework for navigation cues. Avoid all-over glitch and generic neon fog.
```
