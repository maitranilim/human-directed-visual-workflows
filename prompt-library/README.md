# Prompt library

This is a library of controls, not a list of decorative adjectives.

## Assembly order

1. job and audience;
2. subject;
3. composition;
4. preservation locks;
5. style direction;
6. typography, if needed;
7. palette and lighting;
8. texture and finish;
9. negative constraints;
10. final-result target.

Use only the layers required by the task. Style stacks become less controllable when every keyword competes for attention.
