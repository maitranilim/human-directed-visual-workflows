# Prompt skeletons

These are starting structures, not guaranteed final prompts. Add the job, preservation locks, and exact channel requirements.

## Cyber hacking poster

```text
Create a vertical cyberpunk hacking poster in a retrofuturist,
techno-brutalist direction. Feature a central abstract cybernetic mask built
from circuit geometry. Use black, mint, cyan, and violet accents, restrained
HUD overlays, scanner borders, micro-labels, fragmented stencil type, and
subtle CRT texture. Reserve clear hierarchy for one exact headline. The final
result should feel like a premium gaming-editorial cover, not a collage of
unrelated effects.
```

## Dystopian fashion portrait

```text
Create a dystopian science-fiction fashion editorial centered on a
neural-interface visor. Use a muted olive-gray environment, one controlled
orange headline zone, dark technical clothing, soft rim light, sparse UI
labels, and premium magazine spacing. Preserve all declared identity and
camera locks.
```

## Swiss-grid retro poster

```text
Create a clean retrofuturist poster using a disciplined Swiss grid, strong
black typography, one red accent system, orbital line graphics, minimal
geometric icons, and subtle risograph texture. Keep the layout readable at
thumbnail size.
```

## Esports cyberpunk poster

```text
Create a high-energy esports poster with one masked futuristic subject,
black-and-red warning graphics, sharp diagonal movement, layered HUD cues,
vertical technical labels, and controlled glitch typography. Preserve one
clear focal point and a safe zone for exact event copy.
```

## Dark AI poster

```text
Create a dark AI concept poster with a cybernetic humanoid or mecha subject,
tactical armor, corrupted interface cues, heavy shadow, white brutalist type,
one warning-red accent, and distressed print texture. The result should imply
a classified system without reproducing a real organization or mark.
```

## Neon visor portrait

```text
Create a cinematic portrait featuring a bulky electronic visor, visible
cables, small glowing symbols, magenta-blue neon light, industrial hardware,
shallow depth of field, and atmospheric shadow. Keep skin and materials
believable. Avoid beauty-filter smoothing and generic neon fog.
```
