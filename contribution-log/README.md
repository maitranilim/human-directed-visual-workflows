# Contribution log

This append-only log records human directions that materially changed an AI-assisted visual workflow.

## Entry fields

- date or date range;
- visual job;
- prior model behavior or risk;
- human direction;
- resulting behavior;
- preserved evidence;
- evidence level;
- reusable fragment or workflow;
- limitations.

## Evidence levels

- **A:** output or instruction is directly preserved in this repository.
- **B:** repeated instruction is recoverable from available interaction history.
- **C:** retrospective synthesis, clearly labeled.

Do not publish a private source merely to strengthen the evidence. Privacy and rights outrank completeness.
